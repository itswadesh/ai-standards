## Working on this repo

- This repo is public. Before committing, grep for phone numbers, emails,
  account or template IDs, keys, and business or customer names, and remove them.
- Keep `AGENTS.md` short, because it loads into every session everywhere. Put
  detail in `standards/`, and add a row to the index table for any new topic file.
- Write rules as instructions with the reason in a clause, not as stories. Keep
  examples generic.
